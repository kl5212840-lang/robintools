# /analyze — 单篇文章写作质量分析

## 触发

`/analyze <搜索词>`

## 执行步骤

### 第 1 步：定位文件

复用 `/edit` 命令第 2-5 步搜索逻辑。精准匹配直接进入第 2 步，模糊匹配让用户选。

### 第 2 步：提取正文

读全文渲染函数，提取正文内容。跳过：import/export 语句、组件声明、样式代码、CodeBlock 代码块中的命令（其本身不作分析）。

### 第 3 步：四维分析

#### 3.1 AI 感检测

检查以下模式，标注具体位置：

| 模式 | 说明 |
|------|------|
| ⚠️ 万能过渡句 | "值得一提的是""需要注意的是""总的来说""综上所述" |
| ⚠️ 空洞总结 | 每段末尾机械重复"以上就是……"类型的收束 |
| ⚠️ 功能堆砌 | 只列举功能名称但不给操作方法（"支持 A、B、C、D"且无后续展开） |
| ⚠️ 无数字断言 | 说"大幅提升""显著改善"但无任何量化数据 |
| ⚠️ 模板开场 | "在当今……""随着 AI 的快速发展……""大家好，今天我们来……" |
| ✅ 具体案例 | 有距离的参考点、完整命令、版本号、文件路径 |
| ✅ 踩坑细节 | "如果看到 X 报错，说明 Y 没有配置"类因果句式 |
| ✅ 网络标识 | 标注了国内直连/需科学上网/需中转 |

输出：列出命中模式及位置。无触达则标注"无明显 AI 模板痕迹"。

#### 3.2 句子复杂度与信息密度

| 指标 | 测量方式 |
|------|---------|
| 平均句长 | 每位用户在 100 字样本中的平均句子长度分布。超过 40 字/句的标注 |
| 嵌套层级 | "的"字连续重复出现、多层复句（"不但……而且……因此……但是……"） |
| 信息密度 | 每 100 字正文包含的命令行数、文件路径数、数字（KB/版本号/金额）、参数名数 |
| 填充词 | "基本上""一般来说""通常情况下""众所周知""大家知道""当然" |

信息密度评分标准：
- **高**：每 100 字 ≥ 3 个可操作指令
- **中**：1-2 个
- **低**：< 1 个

输出：密度评分 + 长句位置 + 填充词列表。

#### 3.3 重复分析

区分有价值重复和无价值重复：

**无价值重复**：
- 全文重复（不同段落用不同说辞表达同一个观点，无新增信息）
- 章节末尾机械复述章节开头（复读机）
- 多个 Callout 说同一件事

**有价值重复**：
- 关键命令在多处出现（安装/配置/验证各出现一次，每次面向不同目的）
- 错误信息在"原因"和"解决方案"中各提及（建立因果链）
- 结尾清单式重申步骤（教学目的）

输出：重复内容清单，每条标注"✅ 有价值"或"⚠️ 无价值"。

#### 3.4 读者定位评级

三维打分，1-5 分：

| 维度 | 1 分（萌新友好） | 3 分（中等） | 5 分（需经验） |
|------|-----------------|-------------|---------------|
| **术语密度** | 每个术语第一次出现都有解释 | 常见术语不解释、生僻术语解释 | 大量缩写和专业名词无任何解释 |
| **前置假设** | 不假设任何先验知识，从零开始 | 假设有基本的编程概念（文件、命令行） | 假设会配环境变量、懂 Git、懂网络基础 |
| **步骤独立性** | 每步都可独立执行并验证结果 | 需配合前一步的产出 | 直接说"配置好之后……"跳过安装过程 |

综合建议格式：本文更适合 X，对于 Y 在 Z 处可能需要补充解释。

### 第 4 步：输出分析报告

```
📝 写作分析 — <标题>

   📊 信息密度：高 (高/中/低)
      命令行 8 个/千字，版本号 3 处，文件路径 5 处
      填充词 2 处："一般来说"(第3段) "基本上"(第5段)

   🤖 AI 感：2 处触达
      ⚠️ "值得一提的是"(第4段)
      ⚠️ 第6段末尾空洞总结

   📏 句子：
      平均 22 字/句
      2 处长句可考虑断开(第3段第2句 45字，第7段第3句 52字)

   🔄 重复度：4 处
      ✅ API Key 命令出现 3 次 ← 教学必要
      ⚠️ "配置并不复杂"(第3段) ← 与第2段同义，建议删一处

   👤 读者定位：
      术语密度   ■■■□□ (3/5)
      前置假设   ■■■■□ (4/5)
      步骤独立性 ■■□□□ (2/5)
      → 适合有一定基础的中级用户
        萌新可能在前 2 步"环境变量配置"处卡住
        建议在步骤 2 加一句"什么是环境变量"

   ───────────────
   💡 建议修改项：4 条（见上述标记）
```

## 约束

- 操作等级：L1（只读分析）
- 不修改任何文件，只输出报告
- 不作 AI 生成概率评分（给出具体模式而不给百分比）
- 不分析 CodeBlock 内的命令语法，仅提取可操作指令计数
- 主观分析项（读者定位）显式标注为建议，不允许断言
